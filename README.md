# Personal Expense Tracker

A Python-based command-line application for managing personal expenses using Object-Oriented Programming (OOP) and SQLite database integration.

The Personal Expense Tracker allows users to add, view, update, delete, search, and analyze their daily expenses. It also provides category-wise spending reports, monthly expense summaries, and CSV data export.

The application stores expense records permanently in a local SQLite database, so data remains available even after closing the program.

## Project Overview

Managing daily expenses is important for understanding spending habits and maintaining financial discipline.

This project provides a simple command-line solution for maintaining expense records. Users can record their expenses with relevant information such as date, product name, amount, category, location, and additional notes.

The application uses SQLite for permanent data storage and Python OOP concepts to organize the application logic.

## Features

### 1. Add Expense
- Add a new expense record.
- Enter expense date.
- Enter product or expense description.
- Enter expense amount in Indian Rupees.
- Select an expense category.
- Add location information.
- Add optional notes.
- Automatically generate a unique expense ID.

### 2. View All Expenses
- Display all recorded expenses.
- Show expense ID, date, product, category, amount, and location.
- Display the latest expenses first.
- Show the total number of records.

### 3. Total Spending
- Calculate total spending from all recorded expenses.
- Display the total amount in Indian Rupees.
- Handle empty expense records.

### 4. Category-Wise Expense Report
- Calculate spending for each category.
- Display total spending by category.
- Display the number of transactions in each category.
- Sort categories by total spending.

### 5. Monthly Expense Report
- Generate monthly expense reports.
- Select a specific year.
- Display month-wise spending.
- Calculate the yearly total.
- Show the number of transactions for each month.

### 6. Search and Filter Expenses
- Search expenses by product name.
- Search by location.
- Search by notes.
- Filter expenses by category.
- Filter expenses using a starting date and ending date.
- Combine search and filtering conditions.

### 7. Update Expense
- Find an existing expense using its unique ID.
- Update expense date.
- Update product name.
- Update amount.
- Update category.
- Update location and notes.
- Keep existing values when no changes are required.

### 8. Delete Expense
- Find an expense using its ID.
- Display expense details before deletion.
- Ask for confirmation before deleting.
- Remove the selected record from the database.

### 9. Export Expenses to CSV
- Export all expense records into a CSV file.
- Include expense ID, date, product, amount, category, location, and notes.
- Generate a date-based filename.
- Open exported data using spreadsheet applications such as Microsoft Excel.

### 10. Data Persistence
- Store expenses permanently using SQLite.
- Automatically create the database if it does not exist.
- Maintain records after application restart.
- Use parameterized SQL queries for database operations.

### Step 2: Navigate to the Project Directory


### Step 3: Open the Project in VS Code



Selecting option 3 calculates and displays the total amount spent.

### Category Report

Selecting option 4 displays the total spending and transaction count for each expense category.

### Search and Filter

## Database Structure

The application uses SQLite to store expense records.

**Database Name:** `expenses.db`

**Table Name:** `expenses`

### Table Schema

| Column | Data Type | Description |
|---|---|---|
| id | INTEGER | Unique primary key |
| expense_date | TEXT | Expense date |
| product | TEXT | Product or expense description |
| amount | TEXT | Expense amount |
| category | TEXT | Expense category |
| location | TEXT | Expense location |
| note | TEXT | Additional information |
| created_at | TEXT | Record creation timestamp |

### Primary Key

The `id` column is the primary key and uses AUTOINCREMENT to generate unique expense IDs.

### Database Operations

The application performs the following SQL operations:

- CREATE TABLE - Creates the expenses table.
- INSERT - Adds new expense records.
- SELECT - Retrieves expense records.
- UPDATE - Modifies existing records.
- DELETE - Removes selected records.
- SUM - Calculates total spending.
- GROUP BY - Generates category-wise and monthly reports.
- ORDER BY - Sorts expense records.
